# Icon and UI preview findings

The desktop preview keeps the crown watermark low-contrast and away from the centered hero copy. The header crown remains visually legible without competing with the CTA. The mobile preview keeps the crown mark inside its slot, preserves CTA proportions, and shows no overlap with the sticky navigation. Remaining refinement should focus on making icon containers and secondary UI surfaces use the same warm beveled-gold edge, graphite-black fill, steel highlight, and restrained spectral tint as the crown, while preserving text contrast.
